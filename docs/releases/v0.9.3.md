## 提速

| 项 | 之前 | 现在 |
|---|---|---|
| 解码（1080p） | 128 fps（cv2 每帧两次 resize） | **1529 fps**（ffmpeg 单遍，**11.9×**，60s 素材实测） |
| 解码（16651 帧素材推算） | 103.3 s | **≈ 10 s** |
| 长片 AI（可选抽帧） | 114.0 s | **≈ 57 s**（每 2 帧取 1，可在设置里开关） |
| 整条 9.3 分钟素材 | 270 s | **≈ 180 s**（默认）/ **≈ 125 s**（开快速模式） |

- 解码引擎 `ffmpeg` 失败时自动回退 cv2，并打 warning
- 抽帧只影响渐变转场定位精度（±N 帧），硬切仍由 T1 候选 + 融合精修；`analysis.json` 的 `run.t2_step` 记录实际步长
- 新增 `python tools/bench_detect.py <video> [--fast]`，可直接对比两种解码引擎的耗时与切点

> 精度：合成素材实测 hardcuts / fade 切点完全一致，dissolve 相差 1 帧（在滤波/取整误差内）

## 新增：界面里配置数据目录与工作区

侧栏 **⚙ 设置**：

- **工作区目录**：项目文件夹位置，**立即生效**
- **数据目录**：日志 / 缓存 / 素材池索引 / 设置的位置，可勾选「迁移现有数据」，改完点「重启程序」一键生效
- **长片 AI 加速**：开关 + 抽帧阈值（默认 20000 帧）
- **日志级别**：与底部下拉同步
- 「打开数据目录」直接在资源管理器里打开

解析优先级：`--data-dir` → `SCENECUT_DATA` → 指针文件 `data_root.txt`（exe 同目录）→ `%LOCALAPPDATA%\SceneCut` → 程序目录 `data\` → `%TEMP%`。

迁移只复制不删除，失败时指针不写入、继续使用旧目录。

## 修复/改进

- 工作区切换有检测在跑时返回 409，避免中途换目录
- 目录校验：拒绝相对路径、文件路径、与现有目录互相嵌套的路径，并给出中文原因
- 启动日志打印数据目录来源（`env` / `pointer` / `default`），便于确认是否生效

## 使用

1. 解压到任意目录（**不要**放进 `Program Files`）
2. 双击 `scene-cut.exe`：启动本地服务 + 独立应用窗口（最小 1200×780，关窗即退出）
3. 需要系统 `PATH` 中有 `ffmpeg` / `ffprobe`，或放到 `_internal\_bin\`

## 说明

- 窗口依赖系统 WebView2 运行时（Win10/11 默认自带）
- exe 未签名，首次运行会有 SmartScreen 提示，选“仍要运行”
- 本包不含 ffmpeg；随包分发请用 LGPL 构建（`tools/fetch_ffmpeg_lgpl.py`）
