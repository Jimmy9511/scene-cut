## 使用

1. 解压到任意目录（**不要**放进 `Program Files`）
2. 双击 `scene-cut.exe`：启动本地服务 + 独立应用窗口（最小 1200×780，关窗即退出）
3. 需要系统 `PATH` 中有 `ffmpeg` / `ffprobe`，或放到 `_internal\_bin\`

命令行参数：

```
scene-cut.exe --browser   用默认浏览器打开
scene-cut.exe --tab       用 Edge 普通窗口打开
scene-cut.exe --manual    只把地址复制到剪贴板
scene-cut.exe --no-open   只启动服务
```

## 说明

- 数据默认写入 `%LOCALAPPDATA%\SceneCut`（可用 `SCENECUT_DATA` 指定）
- 窗口依赖系统 WebView2 运行时（Win10/11 默认自带）
- exe 未签名，首次运行会出现 SmartScreen 提示，选“仍要运行”
- 本包不含 ffmpeg；如果要随包分发，请用 LGPL 构建（`tools/fetch_ffmpeg_lgpl.py`）
- 校验方法：
  - Windows：`certutil -hashfile scene-cut-v0.9.1-win64.zip SHA256`
  - Linux/macOS：`shasum -a 256 scene-cut-v0.9.1-win64.zip`
